# GitHub Issues

Всички задачи са създадени в [GitHub Issues](https://github.com/danibot5/Sport-Track/issues) с етикети `week-1` … `week-5` и тип (`frontend`, `database`, `design`, `planning`, `testing`, `documentation`, `enhancement`). Номерата започват от #3, защото #1 и #2 са pull requests.

Разпределение: **Дани** (Ученик 1) – интерфейс, HTML/CSS, Chart.js, дизайн; **Ники** (Ученик 2) – Supabase, JavaScript логика, RLS, алгоритъм, тестове.
