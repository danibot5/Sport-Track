# GitHub Issues

Създайте тези Issues в GitHub (**Issues → New issue**) и ги възложете на посочения член. Добавете ги в GitHub Project (**Projects → New project → Board**) с колони `Todo`, `In Progress`, `Done`.

Етикети: `week-1`, `week-2`, `documentation`, `design`, `database`, `frontend`, `planning`, `testing`.
