# Тестове

## Автоматизирани тестове (Vitest)

Стартиране:

```bash
npm test
```

Тестовете са в папка [`tests/`](../tests). Към Седмица 2 са **34 теста** в 2 файла.

| Файл | Какво проверява | Брой |
| --- | --- | --- |
| `tests/validation.test.js` | имейл, парола, вход, регистрация, упражнение, серия, цел | 20 |
| `tests/router-stats.test.js` | маршрутизация и защита на страниците, седмична статистика, напредък към цел, превод на грешки, почистване на адреса на Supabase | 14 |

Примерни гранични случаи, които се проверяват:

- парола само с букви или само с цифри се отхвърля;
- серия без повторения и без продължителност се отхвърля;
- дробни повторения и отрицателна тежест се отхвърлят;
- срок на цел днес е валиден, а вчера – не;
- напредъкът към цел никога не надхвърля 100%;
- тренировка в неделя попада в същата седмица като понеделник (седмицата започва в понеделник);
- невлязъл потребител, който отваря `#/dashboard`, се пренасочва към `#/login`.

Тестовете се пускат и автоматично в GitHub Actions при всеки push и pull request към `main`.
