# SportTrack

Уеб приложение за ученици и любители на спорта, което помага да планират, записват и проследяват тренировки без да се представя като медицинска система.

## Екип

- Ученик 1: интерфейс, UX и визуализации
- Ученик 2: данни, логика, алгоритъм и тестове

> Преди предаване заменете „Ученик 1“ и „Ученик 2“ с истинските имена.

## Текущ етап

Седмица 1: проучване, планиране, макети, модел на данните и начална структура.
